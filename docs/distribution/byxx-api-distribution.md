# 百业网 API 分发渠道

GEOFlow 通过 `byxx_api` 渠道类型接入百业网公开表单接口。该渠道用于检查信息空间并新增纯文本信息，不复用通用 JSON API 发布器。

## 接口契约

- 基础地址固定为 `https://member.byxx.com`。
- 空间检查：`POST /api_getSpace.php`。
- 新增信息：`POST /api_goods.php`。
- 请求使用 `application/x-www-form-urlencoded`。
- `member_id`、店铺编号和发布分类保存在 `channel_config`。
- `apikey` 按百业网文档解释为登录密码，只保存在加密的 `distribution_channel_secrets` 记录中。

发布器把文章 HTML 或 Markdown 清理为纯文本。图片不上传。成功后保存百业网返回的信息 ID，公开 URL 需要从店铺页人工回读。

百业网当前接口没有信息查询、修改、删除或图片上传能力。GEOFlow 后台对该渠道隐藏远端修改、远端删除、站点设置同步和目标站点包入口，并在分发记录中提示到百业网后台处理。

## 状态与验证

暂停渠道可以在没有密码时先保存 UID 和店铺资料。启用渠道必须存在加密密码；无密码渠道不能直接激活。更换密码会撤销旧密钥并建立新的加密密钥。

取得真实密码后按以下顺序联调：

1. 在编辑页填写密码并保持渠道暂停。
2. 调用空间检查，确认 `member_id`、账号状态和 API 套餐权限。
3. 检查返回的总量、已用量和可用量。
4. 启用渠道后，只发布一篇已经人工审核通过的文章。
5. 保存返回的信息 ID，并从公开店铺页回读文章 URL。

不要通过多个 UID 反复试错。业务码 `402` 表示密码错误，`405` 表示套餐无 API 权限，`406` 表示店铺已禁用，`409` 表示标题重复。
