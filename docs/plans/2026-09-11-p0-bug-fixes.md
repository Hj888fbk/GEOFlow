## B8 修复细节

**新增文件**：`app/Console/Commands/RecoverStaleBrowserClaimsCommand.php`（200 行）

**为什么用独立类命令而不是 routes/console.php 里的 closure 命令**：closure 命令在 routes/console.php 顶层 use 进来的类无法被闭包内部解析（Laravel 启动时序问题），首次尝试就走通了 `Class "ManualPublication" not found`。独立类命令在 Laravel 完整启动后才被解析，避开这个坑。

**命令签名**：
```
geoflow:recover-browser-claims {--stale-after=} {--limit=100} {--dry-run}
```

**核心逻辑**（位于 `handle()`）：
1. 默认阈值 = `ManualPublicationBrowserService::STALE_AFTER_MINUTES`（10 分钟）
2. 仅扫描 `status = IN_PROGRESS` 且 `browser_last_seen_at < cutoff` 的记录
3. **不动 `draft_filled`**（平台端已有数据，回收会丢失工作）
4. 每条用 `DB::transaction(closure, attempts: 3)` + `lockForUpdate`，**双检**：循环期间心跳可能又跳到，必须二次校验 last_seen_at
5. 释放回 `ready`：清 `browser_claimed_by_token_id`、`browser_claimed_at`、`browser_last_seen_at`，`revision + 1`
6. 写 `ManualPublicationTransition` 审计行（`changed_by_admin_id = NULL`，因为是系统命令而非用户操作；`result_note` 包含原 token_id 和 cut_off_min 便于追责）
7. 单条失败仅记 Log::warning，不中断整批

**调度**（在 `routes/console.php`）：
```php
Schedule::command('geoflow:recover-browser-claims', ['--stale-after' => 20])
    ->everyFiveMinutes()
    ->onOneServer()
    ->withoutOverlapping(10);
```

阈值 20 分钟 = STALE_AFTER_MINUTES (10) × 2，避免误杀真实在跑的浏览器扩展。

**验证**：

```bash
# 1. 命令注册
php artisan list | grep recover-browser-claims
# 预期：geoflow:recover-browser-claims   Release manual_publication browser claims ...

# 2. dry-run（不会改 DB）
php artisan geoflow:recover-browser-claims --dry-run
# 预期：No browser claims older than 10 minutes ...

# 3. 构造一条 stale claim 来验证真实回收
php artisan tinker --execute='
  $p = App\Models\ManualPublication::where("status","in_progress")->first();
  if (!$p) { echo "没有 in_progress 行可用于测试"; exit; }
  $p->browser_last_seen_at = now()->subMinutes(45);  // 45分钟前的心跳
  $p->save();
  echo "构造 stale: pub_id=".$p->id." last_seen=".$p->browser_last_seen_at;
'

# 4. 真实执行
php artisan geoflow:recover-browser-claims
# 预期：Recovered 1 stale browser claim(s) → ready.

# 5. 验证 transition 日志
php artisan tinker --execute='
  $t = App\Models\ManualPublicationTransition::where("to_status","ready")
      ->where("result_note","like","stale-claim%")
      ->orderBy("id","desc")->first();
  echo "Transition: ".json_encode($t->toArray(), JSON_UNESCAPED_UNICODE);
'

# 6. 调度已注册
php artisan schedule:list | grep -B 1 -A 3 "recover-browser-claims"
# 预期：每 5 分钟一次，阈值 20
```
