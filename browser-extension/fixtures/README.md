# 百家号与搜狐号适配器模拟说明

当前自动化模拟位于 `tests/JavaScript/browser-extension.test.js`，使用最小 DOM 节点覆盖以下契约：

- 账号错误时不读取或写入编辑器；
- 验证码出现时停止；
- 标题、摘要、正文、标签任一非空时，在所有写入发生前停止；
- 必需 DOM 缺失时返回 `editor_dom_changed`；
- 页面字段 `maxlength` 超限时返回 `field_limit_exceeded`；
- 百家号可用主页 URL 或 UID 完成账号核验；
- 标题、摘要、纯文本正文与标签能够填充；
- 适配器代码不查找、不调用发布按钮；
- 只有百家号公开文章 URL 或搜狐公开文章 URL 被识别为完成页。

这些模拟夹具不是平台真实页面快照，不证明选择器当前仍与线上 DOM 一致。选择器变更只能在专用账号、专用 Chrome Profile 的“只填不发”UAT 中确认；确认前不得扩大适配器启用范围。
